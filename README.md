# 🎮 Game Discovery

A frontend practice project inspired by [RAWG.io](https://rawg.io), built to explore modern React development and create an interactive video game discovery experience.

🚀 **[Live Demo On Vercel](https://react-video-game-hub.vercel.app/)**

### ✨ Features

- Browse and discover video games
- Search games and filter by genre
- Sort games by different criteria
- Responsive user interface

### 🛠️ Tech Stack

- React 19 & TypeScript
- Vite
- Chakra UI & Bootstrap
- RAWG Video Games Database API

### 🚀 Getting Started

```bash
git clone https://github.com/MahdiTajikKazemi/react-video-game-hub.git
cd react-video-game-hub
npm install
npm run dev
```

Configure the required environment variables in a `.env` file before running the project if you want to use your token for any particular reasons. i put mine inside `.env.example` to make your job easier.
